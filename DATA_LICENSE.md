# Data licenses and credits

The MIT license in `LICENSE` covers the code only. The processed data in `web/public/data/` is derived from the sources below, and each keeps its source's terms.

| Source | Used for | Terms |
|---|---|---|
| U.S. Census Bureau: ACS 5-year detailed tables and PUMS | Residential demographics, diaspora detail | U.S. government work, public domain |
| NYC Department of City Planning, via NYC Open Data | Tracts, NTAs, boroughs, tract-to-NTA equivalency | [NYC Open Data Terms of Use](https://opendata.cityofnewyork.us/overview/#termsofuse) |
| NYC DOHMH Restaurant Inspection Results, via NYC Open Data | Restaurants, primary cuisine labels, multi-location flags | [NYC Open Data Terms of Use](https://opendata.cityofnewyork.us/overview/#termsofuse) |
| OpenStreetMap | Inferred cuisine tags, places of worship | © OpenStreetMap contributors, [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |
| Overture Maps Foundation: Places | Inferred cuisine tags | [CDLA-Permissive-2.0](https://cdla.dev/permissive-2-0/) |
| OpenFreeMap basemap (loaded at runtime, not stored here) | Background map tiles | © OpenFreeMap, © OpenMapTiles, © OpenStreetMap contributors |

## OpenStreetMap share-alike

The processed files that contain OpenStreetMap-derived information include the restaurant files with cuisine tags and `worship.json`. To the extent they form a derived database of OpenStreetMap data, they are made available under the ODbL 1.0. Anyone reusing them must credit "© OpenStreetMap contributors" and keep derived databases under the same license.

This file is a good-faith summary of the sources' terms, not legal advice. The sources' own terms govern.
